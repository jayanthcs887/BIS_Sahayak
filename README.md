# 🇮🇳 BIS Sahayak

## AI-Powered Assistant for Indian Standards & BIS Services

BIS Sahayak is a prototype of an AI-powered intelligent assistant designed to help industries, MSMEs, startups, students, and consumers access information related to the **Bureau of Indian Standards (BIS)** and Indian Standards.

This prototype is developed for the **Smart India Hackathon 2026 Internal Hackathon**.

---

## 🎯 Problem Statement

**SIH26107 — AI-powered Intelligent Assistant for Indian Standards and BIS Services for Industries and Consumers**

Users often need to navigate complex information related to:

- Indian Standards
- BIS Product Certification
- ISI Mark
- Hallmarking
- Testing & Laboratories
- Consumer Services
- Certification Requirements
- BIS Services and Procedures

BIS Sahayak provides a simple conversational interface to make this information easier to explore.

---

## 💡 Prototype

The current version is a **functional web prototype** demonstrating the proposed user experience and core interaction flow.

### Prototype Flow

User  
↓  
Ask a BIS-related Question  
↓  
BIS Sahayak  
↓  
Relevant Information  
↓  
Source / Reference

The prototype demonstrates how users can interact with the assistant and receive BIS-related information through a conversational interface.

## 🚀 How to Run

### Option 1 — Open Directly

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

### Option 2 — Using VS Code

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

## ⚠️ Prototype Disclaimer

This repository contains an **early-stage prototype** created for the Smart India Hackathon internal evaluation.

The current prototype uses **demonstration/curated information** and is **not connected to live BIS systems or databases**.

The information displayed in this prototype should not be considered an official BIS source for certification, compliance, testing, or regulatory decisions.
